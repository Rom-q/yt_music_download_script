# Пачка скриптов для скачивания музыки с *видеохостинга youtube* без запары   
Сделанно за несколько деньков в состоянии **соплеизливания**
## В репозитории есть несколько модулей:
1. add_cover.py - добавляет обложки к трекам
2. metadata_trigger.py - достает метаданные и создает копии файлов с этими данными
3. yt_downloader - качалка видео или звука с ютуба

В [Releases]() есть собранный .exe где можно сделать все сразу 

При скачивании видео можно выбрать любое доступное качество от **360** до **4к** для видео и от **128** до **320** для звука


~~Для скачивания звука с ютуб требуется [FFmpeg](https://www.gyan.dev/ffmpeg/builds/)~~     
FFmpeg вшит в програмку для вашего удобства


Требующиеся пакетсы: 
- yt-dlp
- spotipy
- mutagen
